🎨 产品组合器 · 前端样式规范 v1

Vue 3 + TypeScript + Vite + Naive UI 项目的视觉基线。沿用 web/index.html 的苹果风，本文档把所有令牌（颜色/字号/间距）规范化，作为后续开发的视觉标准。

1技术栈最终敲定

前后端 TypeScript，类型贯通，单一语言学习成本。

🖥️ 前端

  • Vue 3 + TypeScript Composition API
  • Vite 5 构建（极速）
  • Naive UI 组件库（TS first，文档优秀，主题切换）
  • Pinia 状态管理
  • Vue Router 路由
  • axios HTTP 客户端
  • pnpm 包管理（更快更省）

⚙️ 后端

  • Fastify + TypeScript
  • tsx 开发热重载
  • papaparse 读 CSV
  • better-sqlite3 概念卡存储（同步 API）
  • zod 请求/响应 schema 校验
  • pino 日志
  • 调 openclaw 走 native fetch
