# 飞书多维表导入说明

## 使用方式

在飞书多维表中新建应用，建议命名：

```text
淘玛特立项专家
```

然后按顺序创建 6 张表：

1. `01_产品立项池`
2. `02_立项前模块预判表`
3. `03_立项评分表`
4. `04_立项路径产出表`
5. `05_立项任务分发表`
6. `06_立项复盘表`

每张表可以用对应 CSV 导入字段：

| 飞书表 | CSV 文件 |
|---|---|
| 01_产品立项池 | `01_product_initiation_pool.csv` |
| 02_立项前模块预判表 | `02_module_precheck.csv` |
| 03_立项评分表 | `03_initiation_scorecard.csv` |
| 04_立项路径产出表 | `04_path_output.csv` |
| 05_立项任务分发表 | `05_task_dispatch.csv` |
| 06_立项复盘表 | `06_initiation_review.csv` |

## 注意

CSV 导入后，飞书通常会把字段先识别成文本。导入完成后，需要手动把字段类型改成表中标注的类型：

- 单选
- 多选
- 人员
- 日期
- 关联
- 附件/链接
- 数字
- 长文本

## 关联关系

建议建立以下关联：

| 来源表 | 字段 | 关联到 |
|---|---|---|
| 02_立项前模块预判表 | 立项ID | 01_产品立项池 |
| 03_立项评分表 | 立项ID | 01_产品立项池 |
| 04_立项路径产出表 | 立项ID | 01_产品立项池 |
| 05_立项任务分发表 | 立项ID | 01_产品立项池 |
| 06_立项复盘表 | 立项ID | 01_产品立项池 |

## 自动化建议

1. `01_产品立项池` 新增记录后，调用淘玛特立项专家。
2. 先生成 `02_立项前模块预判表`，判断模块复用率和模块闸口。
3. 再生成 `03_立项评分表`，模块复用价值按20分计算。
4. 根据四类项目写入 `04_立项路径产出表`。
5. 创建 `05_立项任务分发表`。
6. 项目结束后写入 `06_立项复盘表`。

## 模块闸口

| 立项前模块复用率 | 结论 |
|---:|---|
| >=70% | 模块高复用，可快速推进 |
| 40%-69% | 模块中等复用，建议小样测试 |
| <40% | 模块低复用，默认暂缓 |
| 核心模块缺失且供应链不可确认 | 核心模块缺失，不建议直接立项 |
