# 淘玛特产品组合器（Product Composer）

> 状态：v1 设计阶段 · 重构自前期"立项专家"方向 · 2026-05

## 这是什么

淘玛特品牌产品增长中心内部工具——用一句话描述想要什么，AI 用模块库的积木拼出产品草案。

- **用户**：产品部 4 人（党英轩、曹树洋、黄学善、那日苏）
- **核心交互**：自然语言输入 → 5 维度解析 → 模块匹配 → 自由畅想 → 产品概念卡
- **不做**：立项审批、评分卡、对外开放、项目管理

## 重要原则

1. **数据驱动判断，不让 AI 瞎判**——项目类型由"触发路径 + 数据匹配"决定，不靠 AI 自动分类
2. **内层外层分明**——内层 07 模块库可直接落产，外层 10 外部素材库需立项验证
3. **来源标签 ≠ KPI**——靠"我的模块被引用 N 次"驱动贡献，不强制填表
4. **不做就是不做**——立项审批、评分卡、对外开放，永远不做

## 关于 archive/ 目录

archive/ 里的文件是早期"立项专家"方向的产物。**当前不再使用**，但保留在仓库里方便：
- 查 git 历史的连续性
- 若未来某个机制要复用（如评分锚点逻辑），可以从这里挖
- 给团队一个"我们怎么走到今天"的回溯路径

**不要往 archive/ 里加新东西**，那是冷库。
